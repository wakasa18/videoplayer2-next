# Damon’s Archive User Guide

## Sign in and account access
Open the production website, sign in with the registered Supabase account, and use Settings to update the display name or password. Sign out after using a shared or public computer.

## Important Files
Use Important Files to upload files, create folders, rename or move content, preview supported formats, download originals, star important items, and move unwanted items to the Recycle Bin. Restore items from the Recycle Bin before permanent deletion.

## Shared links
Create a shared link for a file or folder, set the access level, expiration, download permission, and optional message. Test the public link in a private browser window. Revoke links that are no longer needed.

## Assignments
Create assignments with subject, priority, due date, recurrence, notes, subtasks, and attachments. Use List, Board, or Calendar view. Mark assignments complete only after the work is finished.

## Videos
Upload browser-compatible MP4 or WebM when possible. MKV files may be stored but browser playback depends on the codecs inside the container. Use the repair action when a migrated video record points to a missing Storage object.

## Activity and notifications
Use Activity to review important actions. Assignment notifications show reminders and due items. Report unexpected actions to the system administrator.

## Safe daily use
Do not share account passwords or secret links. Confirm large uploads finish before closing the page. Keep a local copy of critical files. Use the Download button rather than relying on preview mode.
