# Dashboard React Error #441 Fix

## Cause

`app/dashboard/page.tsx` is a Server Component. It previously passed imported Lucide icon components, such as `FolderOpen` and `Settings`, into `components/dashboard-reveal.tsx`, which is a Client Component because it uses Motion animations.

React Server Components cannot serialize ordinary component functions across that boundary.

## Correction

The server page now passes string identifiers such as `folder-open` and `settings`. The Client Component owns the Lucide imports and converts each identifier into the correct icon before rendering.

## Files changed

- `app/dashboard/page.tsx`
- `components/dashboard-reveal.tsx`
- `PACKAGE_NOTE.md`
