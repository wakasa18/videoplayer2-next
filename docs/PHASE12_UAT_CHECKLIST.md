# User Acceptance Testing Checklist

## Authentication
- Sign in and sign out
- Password reset and password update
- Unauthorized dashboard access redirects correctly

## Files
- Upload file and folder
- Preview supported file
- Download original file
- Rename, move, star, recycle, restore, and permanently delete

## Sharing
- Create file and folder link
- Test preview and download permissions
- Test expiration and maximum download settings
- Download selected files and complete folder ZIP

## Assignments
- Create, edit, complete, archive, and restore
- Test reminders, recurring schedules, subtasks, notes, and attachments

## Videos
- Upload, play, seek, download, rename, and delete
- Test missing-object repair
- Confirm unsupported codecs show a useful message

## Operations
- System Check has no failed critical item
- Maintenance has no critical warning
- QA has no failed automated check
- Metadata backup verifies successfully
- Production rollback path is known and tested
